This repository documents my hands-on learning journey with the Metasploit Framework in controlled lab environments (TryHackMe).

The goal of this project is to strengthen my understanding of cybersecurity fundamentals, offensive security concepts, and practical troubleshooting skills — always in ethical and educational contexts.

## 🚀 What I Practiced

- Understanding the architecture of the Metasploit Framework

- Network communication basics and troubleshooting  
- Environment setup and debugging issues
